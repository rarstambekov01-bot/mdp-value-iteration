## Сипаттама

Қоймадағы жеткізу роботы `S` нүктесінен `G` нүктесіне жетуі керек. Еден сырғанақ,
сондықтан робот таңдаған бағытқа 80% ықтималдықпен барады, 10% солға және 10% оңға ауытқиды.
Жұмыста MDP сипатталады және **мәндер итерациясы (Value Iteration)** арқылы әр ұяшық үшін ең жақсы әрекет (саясат π) табылады.

```
A  B  C  G (+10)
D  #  E  X (-10)
S  F  H  I
```

- `G` - мақсат (+10), `X` - қауіпті ұяшық (−10), `#` - қабырға, әр қадам −0.1
- γ (дисконттау) = 0.9, тоқтау шарты θ = 0.001

## Нәтиже (γ = 0.9, 16 итерация)

| Күй | V | Саясат π |
| --- | --- | --- |
| A | 6.90 | → |
| B | 8.12 | → |
| C | 9.39 | → |
| D | 5.94 | ↑ |
| E | 6.23 | ↑ |
| S | 5.01 | ↑ |
| F | 4.29 | → |
| H | 5.02 | ↑ |
| I | 2.77 | ← |

Ең ықтимал маршрут: **S → D → A → B → C → G** (қауіпті X-тен алыс).

## Эксперименттер

| № | Өзгеріс | Саясат өзгерісі |
| --- | --- | --- |
| 1 | γ: 0.9 → 0.2 | тек I: ← → ↓ |
| 2 | негізгі қозғалыс: 0.8 → 0.6 | E: ↑ → ←, F: → → ←, I: ← → ↓ |
| 3 | X айыппұлы: −10 → −30 | F: → → ←, H: ↑ → ←, I: ← → ↓ |
| 4 | қадам марапаты: −0.1 → −1 | саясат өзгермейді, барлық V төмендейді |
